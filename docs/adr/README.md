# Architecture Decision Records

Utiliser un ADR pour les décisions de transport, SSO, parent-child bridge, fullscreen navigateur, persistance du mode, nouvelle SurfaceKind ou changement de boundary.

Les ADRs ne remplacent pas les contrats propriétaires. Ils enregistrent une décision Koali dans son scope.

Accepted architecture decisions include `0002-product-ui-standalone-and-composable.md`, which defines product removability, standalone operation and declarative integrated surface profiles.
