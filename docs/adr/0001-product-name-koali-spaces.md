# ADR-0001 — Nom public Koali Spaces

**Statut : Accepted**

## Décision

Le nom public et documentaire du produit est **Koali Spaces**.

`koa_spaces` reste un identifiant technique d’intégration existant tant qu’un changement coordonné avec kOA-Linux n’est pas effectué.

Les nouveaux fichiers, titres UI, metadata produit et documentation interne utilisent Koali Spaces. Une référence explicite à un fichier/identifiant host existant peut conserver `koa_spaces` pour compatibilité.

## Conséquence

Cette décision empêche la dérive de branding « kOA Spaces » dans le repository Koali Spaces sans exiger une migration atomique immédiate de tous les contracts hôtes.
