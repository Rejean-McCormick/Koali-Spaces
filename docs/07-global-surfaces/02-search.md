# Search

**Classe : Cible produit**

Search agrège des résultats provenant de providers enregistrés.

Provider minimal recommandé : `provider_id`, owner, query capabilities, scopes, offline state, result items avec title/summary/kind/owner/target route.

Koali peut classer et présenter les résultats ; il ne crawlera pas directement les stores propriétaires sans contrat.

Un résultat ouvre une route déclarée du propriétaire.
