# Annexe D — Terminologie canonique v1.1

| Terme | Sens |
|---|---|
| Surface Layer | couche Koali qui résout et rend des surfaces sans absorber leur autorité métier |
| SurfaceRenderer | dispatcher browser de surfaces déjà résolues |
| ApplicationHost | host browser d'une `local_module_surface` |
| RuntimeRegistration | enregistrement technique server-side d'un runtime |
| SurfacePresentationPolicy | politique d'expérience Koali, distincte du runtime |
| ResolvedSurfaceInternal | résultat server-only de résolution complète |
| SurfaceDescriptorPublic | projection minimisée destinée au navigateur |
| framed | application imbriquée avec chrome Koali minimal |
| immersive | application occupant la surface Koali sans chrome principal ; ce n'est pas Browser Fullscreen |
| lifecycle owner/broker | propriétaire autorisé des opérations start/stop/activate du runtime |
| ApplicationConformanceProfile | preuve/configuration d'onboarding d'une application propriétaire |
| transport profile | référence fermée décrivant comment un runtime admis devient une target browser sûre |
