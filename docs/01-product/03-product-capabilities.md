# Carte des capabilities de Koali Spaces

**Classe : Référence architecturale**

## Capabilities natives du produit

- shell global ;
- Space activation view state ;
- module registry ;
- route composition ;
- sidebar composition ;
- topbar composition ;
- theme bridge ;
- localisation ;
- offline presentation ;
- Surface Renderer/Application Host ;
- Search/Tasks/Status aggregation via providers ;
- interface health ;
- presentation settings ;
- compatibilité standalone/intégrée déclarée par manifest.

## Capabilities projetées

Koali peut utiliser une liste de capabilities fournie par kOA pour filtrer la présentation. Cette liste ne peut jamais être étendue par Koali lui-même.

## Capabilities propriétaires

Une capability d’un module appartient toujours au système qui la fournit. Koali ne déduit pas son comportement à partir du nom de la capability.
