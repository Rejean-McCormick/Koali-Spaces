# Principes d’expérience

**Classe : Normatif**

- **Local-first** : le shell de base ne dépend pas d’Internet.
- **Contextuel** : le Space actif détermine les modules et labels visibles.
- **Prévisible** : module selector en haut à gauche, top bar partagée, navigation de module, surface principale.
- **Faible bruit visuel** : surfaces neutres, accent contenu, états explicites.
- **Owner-preserving** : l’application intégrée reste reconnaissable et garde son interaction interne.
- **Progressive disclosure** : la complexité apparaît au besoin.
- **Accessible par défaut** : keyboard, focus, labels, reflow, reduced motion.
- **Fail visible** : l’utilisateur voit offline/degraded/unavailable plutôt qu’un faux succès.
- **Continuity** : reprise du dernier emplacement permis quand cela reste valide.
