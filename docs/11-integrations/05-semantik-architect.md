# SemantiK Architect

**Classe : Boundary d’intégration**

SemantiK Architect conserve son frontend, son planner-centered runtime, ses APIs, jobs et artifacts.

Koali l’héberge comme application propriétaire lorsque le runtime est admis. Les tools internes (ex. GF Wordbench) restent du tooling Architect et ne deviennent pas des modules Koali autonomes sans contrat séparé.
