# Glossaire

**Koali Spaces** — produit d’expérience local-first.  
**Space** — configuration utilisateur/contextuelle de présentation.  
**Space definition** — artifact déclaratif d’un Space.  
**Module interface manifest** — contribution de routes/navigation/widgets d’un owner.  
**Interface module** — identité de présentation stable ; ne suffit pas à définir l’ownership architectural.  
**Surface** — contenu rendu dans la main page surface.  
**Surface Renderer** — dispatcher des SurfaceKinds.  
**ApplicationHost** — host UI d’une application propriétaire déjà résolue.  
**Framed** — Koali chrome visible autour de la surface.  
**Immersive** — chrome Koali principal masqué, sortie parent-owned conservée.  
**Capability projection** — snapshot non autoritative utilisée pour filtrer la présentation.  
**Owner** — système/composant possédant l’autorité sur une donnée ou action.
