# Module Selector

**Classe : Normatif**

Le selector en haut à gauche affiche les modules : enabled dans le Space, admis et compatibles avec les capabilities visibles.

Sélectionner un module choisit sa route home sûre en fonction du network state et des capabilities.

Le label public vient du Space lorsqu’il existe, sinon du manifest.

Cible : supporter `home_route_override`, icon refs, localisation des labels et reprise de dernière route sûre par module.
