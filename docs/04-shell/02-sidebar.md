# Sidebar

**Classe : Normatif**

La sidebar globale est alimentée par le manifest du module actif.

- profondeur visible : 2 ;
- groupes vides omis ;
- enfants filtrés par capabilities et route availability ;
- desktop : sidebar persistante ;
- mobile : Drawer ;
- focus restauré à la fermeture ;
- badges sont présentation-only.

Une application hébergée peut garder sa navigation interne dans la surface principale. La sidebar Koali ne doit pas tenter de reproduire toute la navigation interne de l’application.
