# Modèle de tests

**Classe : Normatif**

Niveaux : unit TypeScript, component UI, runtime Node, contract/schema, build, runtime smoke, surface integration, security browser et offline.

Chaque bug architectural trouvé manuellement doit être converti en test lorsque raisonnable. Exemple : le launcher standalone doit avoir un smoke test pour éviter le retour d’un `pages/app directory` error.
