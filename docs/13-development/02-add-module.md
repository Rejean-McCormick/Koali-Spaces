# Ajouter un module d’interface

**Classe : Procédure**

1. identifier l’owner ;
2. fournir un module interface manifest valide ;
3. définir home route, routes, sidebar, widgets, capabilities, offline state ;
4. ajouter la module instance au Space candidat ;
5. valider collisions et safe fallbacks ;
6. vérifier localisation/accessibilité ;
7. si la route est une application complète, suivre l’onboarding Surface Layer ;
8. tester online/offline et denied state ;
9. activer atomiquement via le control path.
