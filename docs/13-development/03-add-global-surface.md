# Ajouter une surface globale Koali

**Classe : Procédure**

Une surface globale n’est justifiée que si elle appartient réellement à l’expérience cross-module.

Checklist : owner = Koali, route globale non collidente, PageShell cohérent, données via providers non autoritatifs, offline policy, localisation, accessibilité, tests, aucune mutation propriétaire directe.

Éviter de créer une page globale simplement pour contourner l’UI d’un owner.
