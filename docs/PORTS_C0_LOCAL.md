# Ports C0 — Koali Spaces

The Koali shell is bound to `127.0.0.1:21170`. The launcher reserves only its known local service ports and never treats an unrelated listener as Koali. The Konnaxion/Orgo integration descriptors allocate isolated instances when Koali launches these products; host standalone instances have separate ports. Some historic reservedPorts remain until their owners are assigned dedicated allocations in C0.
