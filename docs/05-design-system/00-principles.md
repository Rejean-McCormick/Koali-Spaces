# Design system — principes

**Classe : Normatif**

Koali Spaces vise : neutralité, faible bruit visuel, densité cohérente, focus visible, états sémantiques clairs et continuité avec les applications Koali/Konnaxion lorsque leurs conventions sont génériques.

L’alignement visuel ne transfère aucune propriété de code ou de domaine.

Le thème de référence utilise actuellement `#1e6864` comme accent principal, mais les modules hébergés peuvent avoir un accent contextuel séparé selon la Surface Layer.


## Grammaire UX partagée

Le design system définit une grammaire réutilisable : product selector, surface navigation, context header, workspace, inspector contextuel optionnel, drawer mobile et PageShell. Cette grammaire peut être utilisée par Koali Spaces en mode intégré ou par un produit en mode standalone. Les primitives partagées ne contiennent pas de concepts métier Orgo/Konnaxion/Kristal.
