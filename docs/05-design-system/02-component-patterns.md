# Patterns de composants

**Classe : Normatif**

Patterns communs : ModuleSelector, navigation, topbar widget, PageShell, card, description panel, table, form, modal, drawer, alert, notification, empty state, loading, offline/degraded banner.

La stack de référence peut utiliser Ant Design/Pro Components. Les wrappers Koali portent les defaults de présentation ; ils ne deviennent pas des services métier.
