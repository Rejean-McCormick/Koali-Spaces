# Identité visuelle du contexte applicatif

**Classe : Normatif**

Lorsqu’une application complète est nested dans Koali, l’utilisateur doit comprendre qu’il est entré dans un autre contexte sans que Koali recolore l’UI propriétaire.

Le chrome framed recommandé reste minimal : accent/rail discret, nom accessible du contexte et contrôle immersif. Éviter une deuxième grosse barre Koali au-dessus d’une application qui possède déjà sa topbar.

En immersive, le chrome Koali principal disparaît ; le contrôle de sortie demeure parent-owned.
